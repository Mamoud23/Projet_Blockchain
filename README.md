# Simulation d'attaque par éclipse sur wallet SPV

## 📖 Description
Ce projet simule une attaque par éclipse sur un wallet SPV (Simple Payment Verification) dans un contexte de réseau mobile 3G/4G.

## 🎯 Question de recherche
**Comment les caractéristiques des réseaux mobiles 3G/4G augmentent-elles la faisabilité d'une attaque par éclipse sur un wallet SPV ?**

## 📊 Résultats obtenus
- ✅ Éclipse réussie en **17 secondes**
- 🔴 8/8 connexions malveillantes (100%)
- 📶 84 handovers
- 📴 102 déconnexions

## 🚀 Utilisation

```bash
# Cloner le projet
git clone https://github.com/Mamoud23/Projet_Blockchain.git
cd Projet_Blockchain

# Activer l'environnement virtuel
source venv/bin/activate
